02 · HTML

1. Мэдээлэл оруулах хэсэг

HTML нь вэбсайтын бүтэц. input нь хэрэглэгч бичих талбар, button нь үйлдэл эхлүүлэх товч.

<form class="col" id="myForm">
  <input id="name"
    placeholder="Нэр" required>

  <input id="className"
    placeholder="Анги" required>

  <button type="submit">
    Илгээх
  </button>
</form>
Энэ бол зөвхөн загварын жишээ.

Санамж: id нь JavaScript-д тухайн талбарыг олоход тусалдаг өвөрмөц нэр.

03 · CSS

2. Form-оо дэлгэцийн голд байрлуулах

CSS нь харагдах байдлыг тохируулна. Flexbox ашиглан form-оо хэвтээ болон босоо чиглэлд голлуулж болно.

body {
  min-height: 100vh;
  margin: 0;
  display: flex;
  justify-content: center;
  align-items: center;
}

.col {
  width: 300px;
  padding: 24px;
  border: 2px solid #b9c8ff;
  border-radius: 16px;
  display: flex;
  flex-direction: column;
  gap: 12px;
}
justify-content: center

Хэвтээ чиглэлд голлуулна.

align-items: center

Босоо чиглэлд голлуулна.

gap: 12px

Элементүүдийн хооронд зай гаргана.

04 · JAVASCRIPT

3. Товч дарахад мэдээлэл цуглуулах

JavaScript нь form-ыг илгээх үйлдлийг барьж аваад input-ийн утгуудыг уншина.

const form = document.getElementById("myForm");

form.addEventListener("submit", function(event) {
  event.preventDefault();

  const name = document.getElementById("name").value;
  const className =
    document.getElementById("className").value;

  console.log(name, className);
});
getElementById()

ID-аар HTML элементийг олно.

.value

Талбарт бичсэн утгыг авна.

preventDefault()

Form-ийн анхдагч refresh үйлдлийг зогсооно.

05 · МЭДЭЭЛЭЛ ИЛГЭЭХ

4. Google Sheets рүү дамжуулах

JavaScript мэдээллийг Web App URL руу илгээнэ. Google Apps Script хүсэлтийг хүлээн авна.

const data = {
  name: name,
  className: className
};

fetch(WEB_APP_URL, {
  method: "POST",
  body: new URLSearchParams(data)

06 · GOOGLE APPS SCRIPT

5. Хүснэгтэд шинэ мөр нэмэх

Apps Script нь Google Sheets-тэй холбогдож, ирсэн мэдээллийг шинэ мөр болгон бичнэ.

function doPost(e) {
  const sheet = SpreadsheetApp
    .getActiveSpreadsheet()
    .getSheetByName("Sheet1");

  const data = e.parameter;

  sheet.appendRow([
    new Date(),
    data.name || "",
    data.className || ""
  ]);

  return ContentService
    .createTextOutput("OK");
}

appendRow() нь хүснэгтийн хамгийн доод хэсэгт шинэ мөр нэмдэг.

Аюулгүй байдал: нийтэд нээлттэй Web App-д хэн ч хүсэлт илгээж болзошгүй. Нууц үг, регистр зэрэг эмзэг мэдээлэл цуглуулахгүй, шаардлагатай бол хамгаалалт нэмнэ.
